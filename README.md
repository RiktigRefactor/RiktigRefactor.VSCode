# RiktigRefactor.VSCode

![Status: planned](https://img.shields.io/badge/status-planned-lightgrey)

A VS Code extension exposing RiktigRefactor refactorings in the editor.
*Riktig* means "correct" in Swedish/Norwegian.

This is a planned implementation of the [RiktigRefactor specification](https://github.com/RiktigRefactor/riktigrefactor.spec). Nothing is implemented yet.
