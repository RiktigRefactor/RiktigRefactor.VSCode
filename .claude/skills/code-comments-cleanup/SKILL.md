# Code comments

Assume the reader can read code.
A comment that says what the code says is noise: it costs reading time and goes stale when the code changes.
Only keep comments that are absolutely necessary.

If a comment seems necessary, consider whether renaming a symbol, extracting a method, or adding a test could make the comment unnecessary.
